# demo_sim

ngspice demos using the decrypted ICsprout55 HSPICE models in
`../icsprout55/libs.tech/ngspice`.

| Netlist      | What it does                                                  |
|--------------|---------------------------------------------------------------|
| `mos_iv.sp`  | Id-Vds curves and Idsat of 1.2V LVT NMOS/PMOS (W=1u, L=min)    |
| `inv_vtc.sp` | Inverter transfer curve, switching threshold and peak gain    |
| `ringosc.sp` | 11-stage ring oscillator: period, frequency, stage delay      |
| `stdcell_ringosc.sp` | Same ring built from `INVX1H7H` standard cells        |
| `stdcell_dff.sp` | `DFFQX1H7H` capture check and clock-to-Q delay            |

Run everything with `./run.sh` (needs ngspice >= 42). CSV waveforms and logs
are written to `out/`.

## Notes

- `.spiceinit` sets `ngbehavior=hsa` so ngspice accepts the HSPICE syntax
  (`.lib` sections, parameter functions, `agauss`, `.option scale`).
- The corner is selected in `models.inc` (`tt_mos`, `ff_mos`, `ss_mos`,
  `fnsp_mos`, `snfp_mos`).
- The models use `.option scale=0.9` and are binned on the shrunk sizes.
  `60n * 0.9` is `5.3999999999999994e-08` in floating point, just under the
  smallest bin's `lmin = 5.4e-08`, and ngspice has no bin tolerance. The
  outermost `lmin`/`wmin` edges in the ngspice model copy are lowered by 0.01%
  so minimum-size devices (L=60n, W=120n) select a bin.
- The standard-cell demos use `libs.ref/<lib>/spice/<lib>.spice`, an ngspice
  copy of the CDL generated by `hacking/cdl_to_spice.py` (run by
  `install.sh`). The CDL itself is untouched.
- The MOS, resistor, MOM and varactor subcircuits in the ngspice model copy
  default to no local mismatch (`mismod`, `resmis_mod`, `mismod_mom`,
  `mismod_var` = 0). Pass `mismod=1` (etc.) on an instance for mismatch
  Monte Carlo.
