# HANDOFF — icsprout55 OpenPDK: gap closure vs sky130 / ihp-sg13g2

## Goal
Bring this OpenPDK packaging of the ICsprout 55nm PDK to the quality of sky130 / ihp-sg13g2 so designs can be signed off with open tools (LibreLane, OpenROAD, KLayout, Magic/Netgen, ngspice). Read `CLAUDE.md` first: architecture, docker environment, known gaps.

## Decisions
- KLayout is the signoff DRC / LVS / antenna; Magic / Netgen are the second, open opinion.
- Generated files are never hand-edited: decks (`hacking/svrf2klayout`), Magic tech + netgen (`hacking/magic/gen_magic_tech.py`), tech LEF antenna (`ant2lef.py`, after `itf2lef.py`).
- Semantics are settled by running Calibre and KLayout on the same layout.
- Results go to the fork too (resulting files, not generators); push only origin, never the fork's `github` remote.
